Instagram 메시지 검색기란?

인스타그램 앱에서는 오래된 DM을 찾으려면 대화방을 한참 위로 스크롤해야 하고, 대화방 안에서 키워드로 검색하는 기능도 제한적입니다. 이 도구는 인스타그램이 공식으로 제공하는 "내 정보 다운로드" 파일을 열어, 모든 대화방을 목록으로 정리하고 메시지 내용을 키워드로 찾을 수 있게 해 줍니다. 예전에 받은 주소, 약속 날짜, 공유받은 링크처럼 다시 찾고 싶은 내용을 빠르게 확인할 때 유용합니다.

사용 방법

  1. 인스타그램 계정 센터 → 내 정보 및 권한 → 내 정보 다운로드에서 일부 정보 → 메시지를 선택합니다.
  2. 형식은 반드시 JSON, 기간은 찾고 싶은 시점이 포함되도록(가능하면 전체 기간) 선택해 요청합니다.
  3. 이메일로 받은 링크에서 ZIP 파일을 내려받은 뒤, 압축을 풀지 않은 채로 위 업로드 영역에 끌어다 놓습니다.
  4. 왼쪽 대화 목록에서 대화방을 고르고, 위쪽 검색창에 키워드를 입력합니다. ↑ ↓ 버튼으로 일치하는 메시지 사이를 이동할 수 있습니다.

자세한 다운로드 순서와 파일 구조는 인스타그램 내 정보 다운로드 방법 총정리에 정리해 두었습니다.

주요 기능

  • 대화방 목록 정리 — 모든 대화방을 최근 대화순 또는 이름순으로 정렬하고, 상대 이름이나 아이디로 대화방을 찾을 수 있습니다.
  • 메시지 키워드 검색 — 선택한 대화방에서 키워드가 들어간 메시지를 강조 표시하고, 몇 번째 결과인지 보여 줍니다.
  • 긴 대화 자동 병합 — 메시지가 많은 대화방은 인스타그램이 message_1.json, message_2.json처럼 여러 파일로 나누는데, 이를 하나의 대화로 합쳐 시간순으로 보여 줍니다.
  • 한글 깨짐 복원 — 아래에서 설명하는 인코딩 문제를 자동으로 바로잡아 한글과 이모지를 정상적으로 표시합니다.

내려받은 JSON을 직접 열면 한글이 깨지는 이유

메시지 JSON 파일을 메모장이나 브라우저로 직접 열면 한글이 \u00ec\u0095\u0088나 ì•ˆë…•처럼 알아볼 수 없는 문자로 보입니다. 파일이 손상된 것이 아니라, 인스타그램이 UTF-8로 된 글자를 한 바이트씩 잘라 각각을 별도의 문자처럼 적어 두었기 때문입니다. "안"이라는 글자는 UTF-8에서 3바이트인데, 이 3바이트가 서로 다른 세 문자로 기록되는 식입니다. 이 도구는 각 문자를 다시 바이트로 모은 뒤 UTF-8로 해석하는 방식으로 원래 글자를 복원합니다.

개인정보는 안전한가요?

메시지 데이터에는 사적인 대화가 그대로 들어 있습니다. 이 도구는 ZIP 파일을 서버로 보내지 않고, 이용자의 브라우저 안에서만 열어 화면에 표시합니다. 새로고침하거나 탭을 닫으면 불러온 내용은 모두 사라집니다. 같은 이유로, 출처를 알 수 없는 사이트에 메시지 데이터를 업로드하는 것은 피하는 것이 좋습니다.

자주 묻는 질문

대화방이 하나도 보이지 않아요.
HTML 형식으로 요청했거나, '메시지' 항목을 선택하지 않은 경우입니다. JSON 형식으로 메시지 항목이 포함된 데이터를 다시 요청해 주세요.
사진이나 음성 메시지도 볼 수 있나요?
현재는 텍스트 메시지 검색에 집중하고 있어, 사진·동영상·음성 같은 첨부 파일은 표시하지 않습니다.
최근 대화가 빠져 있어요.
데이터 다운로드를 요청한 시점까지의 메시지만 파일에 들어 있습니다. 최신 내용이 필요하면 데이터를 새로 요청해야 합니다.
파일 용량이 커서 오래 걸려요.
메시지 데이터만 선택하고 미디어 품질을 '낮음'으로 요청하면 ZIP 용량이 크게 줄어 더 빨리 열립니다.
