01 / Make it yours

하던 일을,
조금 더 가볍게.

매번 메뉴를 찾거나 창을 끌어 옮기는 대신,
원하는 입력과 동작을 한 번 연결해 두세요.

01 — Connections

한 번의 입력에,
내가 정한 동작.

트랙패드 모서리 클릭, 여러 손가락 탭·스와이프, 키보드 단축키를 원하는 동작에 연결하세요. 각 연결은 따로 켜고 끌 수 있습니다.

  • 창 분할절반 · 4분할 · 3분할 · 3분의 2
  • 단축키 보내기자주 쓰는 키 조합을 한 번에
  • 앱 열기필요한 앱을 바로 실행
02 — Your rules

같은 움직임도,
앱에 따라 다르게.

모든 앱에서 쓰는 공통 연결을 만들고, 필요한 앱에는 전용 연결을 더하세요. 같은 입력이 겹치면 현재 앱의 전용 연결이 우선합니다.

모서리의 인식 영역도 내 손에 맞춰 조절할 수 있어요. 제스처 테스트 화면에서는 터치 위치와 최근 인식 결과를 확인할 수 있습니다.

화면은 현재 앱의 실제 UI 코드를 기본 설정으로 렌더링한 예시입니다.

⌘

익숙한 단축키 그대로

원하는 키 조합을 직접 기록하고, 다른 단축키 입력이나 앱 실행에 연결하세요.

최대화와 가운데 정렬은 물론, 이전·다음 디스플레이로 창을 옮길 수 있습니다.

메뉴바에서 조용하게

메뉴바에서 설정을 열고, 로그인할 때 자동으로 시작하도록 선택할 수 있어요.

02 / Ready when you are

시작은 간단하게.

macOS 26 이상에서 사용할 수 있습니다.
제스처 기능에는 호환 트랙패드가 필요합니다.

  1. 01

    다운로드하고, 앱을 옮기세요.

    PadKey.zip의 압축을 풀고 PadKey를 응용 프로그램 폴더에 넣어 실행하세요.

  2. 02

    손쉬운 사용 권한을 허용하세요.

    시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 PadKey를 켜 주세요. 창 배치와 단축키 입력 등에 필요합니다.

  3. 03

    첫 번째 연결을 만들어 보세요.

    메뉴바의 PadKey에서 ‘트랙패드 모서리’ 또는 설정의 ‘동작 연결’을 열어 원하는 동작을 정하세요.

Good to know

궁금할 수 있는 것들.

무료로 사용할 수 있나요?

네. 이 페이지의 Mac용 무료 다운로드 버튼에서 GitHub 공개 릴리스의 앱을 받을 수 있습니다.

어떤 제스처를 지원하나요?

트랙패드 네 모서리 클릭과 3~5손가락 탭, 상하좌우 스와이프를 지원합니다. 모서리 클릭은 물리 클릭과 macOS의 ‘탭하여 클릭하기’에 대응합니다. 시스템 기본 제스처와 겹치면 두 동작이 함께 실행될 수 있으니 겹치지 않게 설정해 주세요.

다운로드한 앱이 열리지 않으면 어떻게 하나요?

macOS 버전이 26 이상인지 먼저 확인해 주세요. 설치 과정의 문제는 아래 GitHub 문의에 macOS 버전과 오류 메시지를 남겨 주세요.

업데이트는 어떻게 하나요?

앱의 자동 업데이트 확인이 켜져 있으면 시작할 때와 이후 약 6시간마다 GitHub의 새 버전을 확인합니다. 새 버전이 있으면 메뉴바에서 설치할 수 있고, GitHub 릴리스에서 직접 받을 수도 있습니다.
