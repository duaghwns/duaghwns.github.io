사용 방법

설치 없이 브라우저에서 바로 실행됩니다. 앱 실행하기를 누른 뒤 폴더 선택으로 분석할 폴더를 고르면 됩니다. 폴더 접근 권한을 묻는 File System Access API를 사용하므로 Chrome 또는 Edge에서 열어주세요. (Safari·Firefox 미지원)

브라우저가 막는 시스템 폴더까지 보고 싶다면, 명령어 없이 Releases에서 Windows·macOS용 앱을 내려받아 더블클릭하세요. 자동으로 브라우저가 열리고 "경로로 스캔" 입력칸이 추가됩니다.

직접 소스로 실행하려면(Python 필요): 

cd DiskMap
python3 server.py
# http://127.0.0.1:8788

왜 버블 맵으로 보나요?

저장 공간이 부족할 때 Finder나 탐색기에서 폴더를 하나씩 열어 '정보 가져오기'로 크기를 확인하면 시간이 오래 걸립니다. DiskMap은 선택한 폴더 안의 항목을 크기에 비례한 원으로 그려서, 어디가 공간을 가장 많이 차지하는지 한눈에 보여 줍니다. 큰 원부터 클릭해 안으로 들어가다 보면, 몇 번의 클릭만으로 실제로 용량을 잡아먹는 폴더나 파일까지 도달할 수 있습니다.

결과를 읽는 방법

  • 원의 크기는 해당 폴더 또는 파일의 전체 용량입니다. 폴더는 그 안에 들어 있는 모든 파일 크기를 합친 값입니다.
  • 폴더를 클릭하면 그 폴더 안으로 들어가 다시 버블 맵을 그립니다. 왼쪽 패널에서 큰 항목 순서로도 볼 수 있습니다.
  • 파일을 선택하면 경로가 복사됩니다. 브라우저는 보안상 Finder나 탐색기를 직접 열 수 없으므로, 복사한 경로로 위치를 찾아가면 됩니다.
  • 권한이 없는 위치는 따로 표시됩니다. 브라우저가 막는 시스템 폴더는 아래의 앱 버전으로 확인할 수 있습니다.

정리할 때 먼저 볼 만한 곳

용량을 많이 차지하는 곳은 대체로 비슷합니다. 다운로드 폴더에 쌓인 설치 파일과 압축 파일, 사진·동영상 원본, 개발 도구가 만드는 빌드 결과물과 캐시, 휴대폰 백업 파일 등이 대표적입니다. 어떤 폴더가 지워도 되는지, 어떤 폴더는 건드리면 안 되는지는 맥 저장 공간이 부족할 때 먼저 확인할 폴더에 자세히 정리해 두었습니다.

DiskMap은 파일을 지우거나 옮기지 않는 읽기 전용 도구입니다. 실제 삭제는 반드시 내용을 확인한 뒤 Finder나 탐색기에서 직접 해 주세요. 중요한 자료는 정리 전에 백업해 두는 것을 권장합니다.

자주 묻는 질문

스캔이 오래 걸려요.
파일 하나하나의 크기를 읽기 때문에 파일 수가 많을수록 오래 걸립니다. 홈 폴더 전체보다 다운로드나 문서 폴더처럼 범위를 좁혀 시작하면 빠릅니다.
앱을 실행하면 경고가 떠요.
앱에 코드 서명이 되어 있지 않아 처음 한 번 경고가 표시됩니다. macOS는 앱을 오른쪽 클릭해 '열기'를, Windows는 '추가 정보 → 실행'을 선택하면 됩니다.
macOS에서 일부 폴더가 비어 보여요.
~/Library 같은 보호된 폴더는 터미널이나 앱에 '전체 디스크 접근 권한'을 주어야 읽을 수 있습니다. 시스템 설정 → 개인정보 보호 및 보안에서 설정합니다.
홈 팔로우 트래커 메시지 검색 MetaShaper DiskMap 가이드 소개 개인정보처리방침
